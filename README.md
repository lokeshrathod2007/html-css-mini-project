# 🎮 Retro Lights Out Game

A retro-style 5x5 Lights Out game built using HTML, CSS, and minimal JavaScript.

## 📌 Project Overview

Retro Lights Out is a browser-based puzzle game where the objective is to turn off all the lights before the 30-second timer runs out.

When a player clicks a tile:
- That tile toggles (ON/OFF)
- Its top, bottom, left, and right neighbors also toggle

The challenge is to switch off all lights within the time limit.

---

## 🧠 Features

- ✅ 5x5 interactive grid
- ⏳ 30-second countdown timer
- 🏆 Win message if completed in time
- ❌ Game Over message if time runs out
- 🔁 Replay button to restart game
- 🕹 Retro arcade styling (neon colors + pixel font)
- 🏠 Home page
- 📖 Instructions page

---

## 🛠 Technologies Used

- HTML5
- CSS3 (Grid, Shadows, Neon Effects)
- JavaScript (Minimal logic for toggle & timer)

---

## 🎨 Design Style

The project uses a retro arcade theme:
- Black background
- Neon glowing lights
- Pixel-style font (Press Start 2P)
- Classic arcade UI feel

---

## 🚀 How to Run the Project

1. Download or clone the repository
2. Open `index.html` in a browser
3. Click PLAY to start the game

No installation required.
